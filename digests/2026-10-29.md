# AI Daily Digest — 2026-10-29

Google's Gemini 4 Carbon takes #1 on the revamped Artificial Analysis Index, Particle AI launches a token-sipping coding model, Liquid AI ships six open-weight 2B models, GitHub takes multi-model orchestration GA, and NVIDIA drops an open transcription model.

## 🔥 Top Stories

**Google launches Gemini 4 Carbon — new strongest model, #1 on Artificial Analysis Intelligence Index v5 at 59.**
Announced Oct 28 by Koray Kavukcuoglu as "our strongest model with state-of-the-art cybersecurity and long horizon capabilities." Second public model of the Gemini 4 generation after Argon (Sep 30). Same day, Artificial Analysis listed Gemini 4 Carbon (High) at Intelligence Index 59 — the new #1 under the v5 methodology — and LMArena added Carbon (High) to the Agent, Text, and Code WebDev arenas. An early single-source TestingCatalog report from Oct 23 preceded this confirmed launch. Availability looks gated — early commentary notes API access is limited.

- [Artificial Analysis changelog](https://artificialanalysis.ai/changelog)
- [LMArena leaderboard changelog](https://arena.ai/company/leaderboard-changelog)

- [Fello AI: benchmarks and pricing](https://felloai.com/gemini-4-carbon/)

**Particle-1 launches — agentic coding model post-trained on DeepSeek V4.1 Flash using ~45% fewer tokens.**
Startup Particle's Oct 28 debut release targets software engineering: RL-trained in internal environments to solve tasks with fewer tokens at comparable accuracy. Reported numbers: 28.4%–52.2% fewer output tokens and 34.4%–51.6% lower cost per task vs the base model across DeepSWE 1.1 (72.57% pass), Terminal-Bench 2.1, ReactBench, and ADE Bench; general benchmarks stay near base (GPQA Diamond 90.40 vs 90.91, MMLU 86.08 vs 85.98). Live on OpenRouter as `particle-ai/particle-1` (added Oct 28).
- [Particle: Introducing Particle-1](https://particle.ai/blog/introducing-particle-1)
- [OpenRouter: Particle-1 pricing/providers](https://openrouter.ai/particle-ai/particle-1)
- [ExplainX: claimed vs verified](https://explainx.ai/blog/particle-1-deepseek-v4-1-flash-45-percent-fewer-tokens-coding-model-openrouter-claimed-vs-verified-2026)

**Liquid AI launches LFM3 — six open-weight ~2B models on one tri-hybrid backbone.**
Announced Oct 27: LFM3-1.7B (text), LFM3-VL-2B (vision), LFM3-Audio-2B (speech), LFM3-Omni-2B, plus two decision models (d1-2B, d1-omni-2B). 256K context, ~1 GB at 4-bit, built to fine-tune on a single GPU; vendor claims 12.7x agentic benchmark gain over predecessor. Already on Ollama for local runs, and LFM3-Audio-2B is trending on Hugging Face.
- [Liquid AI: Introducing LFM3](https://www.liquid.ai/blog/lfm3)
- [Unite.AI summary](https://www.unite.ai/liquid-ai-launches-lfm3-family-of-six-open-weight-2b-class-models/)
- [TechTimes summary](https://www.techtimes.com/articles/329588/20261028/liquid-ai-releases-lfm3-six-open-weight-models-fuse-text-vision-audio-one-2b-backbone.htm)
- [Ollama: LFM3 available locally](https://x.com/ollama/status/2115147945045864766)

**GitHub makes Copilot Fusion generally available at Universe 2026.**
Runtime orchestration that routes each request across Anthropic and OpenAI models instead of making the user pick — merging Project HydraFusion orchestration with auto model selection. Artificial Analysis: scores 2 points below Opus 5.5 in Claude Code at half the cost per task on the Coding Agent Index. Launched alongside Copilot Projects and a deeper code-review tier.
- [GitHub changelog: Copilot Fusion GA](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/)
- [GitHub docs: About Copilot Fusion](https://docs.github.com/copilot/concepts/models/copilot-fusion)
- [Artificial Analysis: Copilot Fusion article](https://artificialanalysis.ai/articles/github-copilot-fusion-orchestrates-anthropic-and-openai-models-to-balance-performance-and-cost)
- [Unite.AI: Universe 2026 roundup](https://www.unite.ai/github-makes-copilot-fusion-generally-available-at-universe-2026/)

**NVIDIA releases Nemotron 3.5 Transcribe — open-weight 30B MoE transcription model.**
~4B active params, promptable, 40-language transcription plus speaker attribution, translation, contextual prompting, and audio understanding in one checkpoint. Ranked first in VoiceArena's 14-system diarization + ASR comparison (per TestingCatalog) and immediately hit #1 in Hugging Face ASR trending.
