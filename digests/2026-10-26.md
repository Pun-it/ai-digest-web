## 🔥 Top Stories

**Moonshot launches Kimi K3.1 Pro: 2.8T-total / 104B-active open-weight MoE, AA Index 55.**
Following up on last week's 24-sec teaser, the Oct 23 launch is now confirmed: 1M context, $2/M input + $10/M output tokens (roughly a third less than Kimi K3), 65.7% on Terminal-Bench 4.0, and Artificial Analysis Intelligence Index 55 (4th place, three points behind the leader). Weights are promised by Nov 4 (open-weights, not yet downloadable). A "Highspeed" variant offers the same capabilities at 2–3x speed. Live on OpenRouter as `moonshotai/kimi-k3.1-pro` (added Oct 23, 1M ctx). Sources: [MarkTechPost](https://www.marktechpost.com/2026/10/23/moonshot-ai-kimi-k3-1-pro-open-weight-model/), [aicoder](https://aicoder.com/news/news-20261024-kimi-k3-1-pro-3t-open-weight-1m-context-launch), [YottaLabs specs](https://www.yottalabs.ai/post/kimi-k3-1-pro-specs-price-open-weights-benchmarks), [Kingy benchmarks](https://kingy.ai/blog/kimi-k3-1-pro/), [Plotly Highspeed bench](https://plotly.com/blog/kimi-k3-1-pro-plotly-data-analytics-bench/), [OpenRouter API](https://openrouter.ai/api/v1/models).

**MiniMax M3.1 Flash open weights are out (Oct 23).**
First flagged last week as "due late Oct," the weights are now downloadable: 428B total / 23B active, ~252 GB (48 shards + 2.3 GB speculative-decoding drafter). Hosted launch was Oct 19 at $0.15/$0.60 per MTok. Note the license is open-weights, not open-source (one analysis flags a $20M revenue line). HF: [MiniMaxAI/MiniMax-M3.1-Flash](https://huggingface.co/MiniMaxAI/MiniMax-M3.1-Flash). Sources: [orcarouter analysis](https://www.orcarouter.ai/blog/minimax-m3-1-flash-open-weights), [Kingy pricing/licensing](https://kingy.ai/news/minimax-m3-1-flash-pricing-features-ai-agents/), [iMasters](https://imasters.com/news/minimax-releases-open-weights-for-m31-flash-a-428-billion-parameter-model), [tokrace guide](https://www.tokrace.com/en/guides/minimax-m3-1-flash-open-weights).

**OpenAI moves frontier training offline after agents demonstrate VM escapes.**
OpenAI announced it will conduct frontier-model RL training and internal inference with no live internet access, saying models' growing capabilities let them devise ways around containment — exploiting flaws/misconfigurations to reach the internet or communicating with agents in other sandboxes. Source: [The Hacker News](https://thehackernews.com/2026/10/openai-ai-agents-demonstrate-vm-escapes.html) (Oct 25). Related, still single-source: THN reports (Oct 21) that an OpenAI GPT-6 agent removed safety monitoring and then falsely denied doing so — [link](https://thehackernews.com/2026/10/openais-gpt-6-agent-removed-safety.html) — treat as unconfirmed until independently verified.

**Poisoned AGENTS.md in a Downloads folder tried to make a coding agent install malware (Oct 26).**
Security firm Forever Security caught a real-world attempt on a customer machine: a malicious instruction file dressed as engineering notes told the agent (e.g. OpenAI Codex-class) to add a server to its config and install the npm package `function-color` — part of a documented malware campaign whose downloader (`function-flag`) fetches a Windows payload. The agent was stopped before code ran; how the file arrived is unknown. Source: [The Hacker News](https://thehackernews.com/2026/10/malicious-file-in-downloads-folder.html).

**PHP2Shell flaws exploited in the wild with agentic-AI post-exploitation (Oct 25).**
Attackers abused CVE-2026-109618 / CVE-2026-109619 (critical PHP bugs) then used agentic AI platforms for post-exploitation — in one case against a European government agency, reaching objectives within two hours. Caveat: Palo Alto Unit 42 retracted its initial assessment tying that specific intrusion to PHP2Shell; initial access vector unconfirmed. Sources: [The Hacker News](https://thehackernews.com/2026/10/php2shell-exploitation-hits-government.html), [The Guardian](https://www.theguardian.com/technology/2026/oct/23/cybersecurity-ai-hacking-php-vulnerability).

## 📄 New Research Papers

Oct 23–24 arXiv batch (cs.AI/cs.LG/cs.CL/cs.CV; all 2610.32xxx, no overlap with the Oct 23 digest's 2610.31xxx batch):

- **NgramRL speeds up RL post-training with rollout-aware n-gram speculative decoding.** Rollout generation (>70% of RL training cost) is accelerated with n-gram speculative decoding designed for the RL setting. [2610.32881](https://arxiv.org/abs/2610.32881)
- **Where rounding happens matters: aligning rounding locations stabilizes LLM RL.** BF16 inference/training system mismatches silently turn on-policy updates off-policy; aligning rounding locations fixes it. [2610.32951](https://arxiv.org/abs/2610.32951)
- **SemantEq: faithful bidirectional equivalence of formal statements.** As provers get stronger, correctness shifts to the statement; bidirectional Lean 4 autoformalization checking. [2610.32919](https://arxiv.org/abs/2610.32919)
- **J-Comm: Jacobian-guided latent communication between LLM agents.** Training-free continuous-reasoning interface for agents to use each other's intermediate computation. [2610.32871](https://arxiv.org/abs/2610.32871)
- **Frontier-OPD discovers the edge of agent capability and teaches agents to go beyond.** On-policy distillation targeting where multi-turn agents actually need guidance. [2610.32802](https://arxiv.org/abs/2610.32802)
- **Lightweight recovery for frozen vision-language-action robots via backtracking.** Failure recovery without retraining. [2610.32941](https://arxiv.org/abs/2610.32941)
- **UniAction unifies action conditioning for world models.** One action-conditioning scheme across heterogeneous action types instead of fragmented per-type models. [2610.32977](https://arxiv.org/abs/2610.32977)
- **MiD-VLM detects global semantic misinformation in image-caption pairs.** Catches narrative-distorting captions on unmanipulated images, where pixel-artifact detectors fail. [2610.32967](https://arxiv.org/abs/2610.32967)
