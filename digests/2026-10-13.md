## 🔥 Top Stories

- **Meta launches Muse Wonder and Muse Wonder Full — its first frontier-class models.**
  Announced Oct 12, aimed at OpenAI and Anthropic. Zuckerberg: "Muse Spark was our first family of models, and now Muse Wonder is a much larger and more advanced class of models that brings us to the frontier." Chief AI officer Alexandr Wang called Wonder "our largest and most capable model yet." The models combine "Active Memory and Active Focus" for personal agents, professional tasks, and sustained coding work. Wonder is available through the Meta Model API and Muse Code; Wonder Full is available to Muse Code subscribers; both will be usable in Meta's new personal agent app "Muse" for paid subscribers. Meta cites Artificial Analysis benchmarks showing Wonder models beating Spark and rival models from Anthropic, OpenAI and Google — though AA also lists Wonder among the most expensive models. Specs: multimodal input (text, images, video, audio, PDFs) → text; Artificial Analysis Intelligence Index v4.3: Wonder (Max) 52, Wonder Full (Max) 56, vs Muse Spark 1.3 (max) at 48 with only a 6-week release gap; Wonder Full ties Claude Sonnet 5.5; strengths in agentic benchmarks (Terminal-Bench, GDPval-AA). On OpenRouter, `meta/muse-wonder` lists 1M context, mandatory reasoning (minimal→max efforts), priced at $4/$20 per M tokens. Per VentureBeat, only the smaller Wonder is available via API so far.

- **Celeris-1 Decision (Celeris, released Oct 8 — BenchLM October tracker).**
  A hosted diffusion language model built for typed probabilistic decisions: takes text/JSON/images and answers Noul/Choice/Score questions with probabilities plus an optional one-sentence explanation, via a System-One-compatible API. Celeris claims it beats Jev 1.13.0 and rivals on accuracy, Brier score, and response time.
