## 🔥 Top Stories

**Google DeepMind unveils Genie 4 — real-time interactive world simulation with native audio.**
Announced Oct 27 as a research preview to trusted testers. Genie 4 generates photorealistic explorable worlds from text/image prompts with real-time steering, advanced physics, natural human motion, and — new for the series — native audio. It builds on Gemini-family capabilities: Gemini Omni anchors simulations in real-world appearance and behavior while other Gemini models supply reasoning to maintain coherence. No public weights or API yet.

## 📄 New Research Papers

arXiv batch 2610.376xx, pub 2026-10-27:

- **Heads of Security — learned per-head attention gates for prompt-injection robustness.** Enforces instruction-data separation via a small set of learned gates redistributing attention between instructions and data. [2610.37657](https://arxiv.org/abs/2610.37657)
- **ThinkWorld — world imagination reinforces chain-of-dynamics reasoning.** Imagined rollouts improve VLA/robotics reasoning beyond action-labeled demo coverage. [2610.37666](https://arxiv.org/abs/2610.37666)
- **Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis.** How agent tool-use scales with synthesized environments. [2610.37648](https://arxiv.org/abs/2610.37648)
- **EnvSched — environment-aware scheduling for rollout-efficient agent RL.** Data management at the environment level under finite rollout budgets. [2610.37609](https://arxiv.org/abs/2610.37609)
- **GEPA-Curator — curated learning for self-improving agents.** Reflective prompt optimization learning from failed rollouts in multi-turn agentic workloads. [2610.37651](https://arxiv.org/abs/2610.37651)
- **VideoLVR — latent visual reasoning over grounded video evidence.** Lets MLLMs revisit and re-ground video evidence instead of relying only on language CoT traces. [2610.37613](https://arxiv.org/abs/2610.37613)
- **Know, then Draw — autoregression for knowledge + diffusion for pixels.** Semantic knowledge from autoregressive pretraining, fine detail from diffusion. [2610.37626](https://arxiv.org/abs/2610.37626)
- **MoI-Bench — image generation/editing benchmark for mobile devices.** Practical user needs plus device constraints; maps capability gaps for on-device image models. [2610.37599](https://arxiv.org/abs/2610.37599)
- **Metacognitive Decoding — efficient inference for diffusion language agents.** Adapts where compute is spent and how much text is generated for parallel-token agents. [2610.37642](https://arxiv.org/abs/2610.37642)
