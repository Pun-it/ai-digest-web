## Top Stories

- **Anthropic launches Claude Haiku 5.5 — fastest, cheapest small model yet, with up to 90% API price cuts.**
  Haiku 5.5 targets high-volume, cost-sensitive tasks (summaries, compactions, DB queries, classification), shipping on Anthropic's platform plus AWS, Google Cloud and Azure under API id `claude-haiku-5-5`, with a 1M-token context window, adjustable effort settings, and support for coding subagents, browser use and computer use. Pricing: up to 90% reduction on short prompts across all four clouds, and Sonnet 5.5 cache reads halved from 20¢ to 10¢ per million tokens. Artificial Analysis benchmarked it the same day: Intelligence Index 43 (Max), 41 (Xhigh), 38 (High), 34 (Medium), 29 (Low) — up ~26 points on the last Haiku a year ago. It also appeared on OpenRouter (`anthropic/claude-haiku-5.5`, plus `:batch` variant) on Oct 7.
  Sources: [Anthropic announcement](https://www.anthropic.com/claude-haiku-5-5) · [VentureBeat](https://venturebeat.com/technology/anthropic-launches-claude-haiku-5-5-with-90-api-price-reduction-matching-gpt-6-luna) · [SiliconAngle](https://siliconangle.com/2026/10/07/anthropic-releases-claude-haiku-5-5-small-model-and-halves-sonnet-5-5-cache-read-prices/) · [aireleasetracker](https://aireleasetracker.com/model/anthropic/claude-haiku-5-5) · [shattered.io](https://shattered.io/claude-haiku-5-5-api-price-cut-75-percent-2026/) · [AA changelog](https://artificialanalysis.ai/changelog) · [OpenRouter](https://openrouter.ai) · [LLM Gateway timeline](https://llmgateway.io/timeline)

## New Research Papers

Fresh Oct 7 submissions (arXiv cs.AI/cs.LG/cs.CL/cs.CV, sorted by date):

- **Decoupling Exploration from Optimization in RLVR** — argues RLVR on top of trained checkpoints mostly optimizes rather than discovers new reasoning strategies. [abs/2610.10536](https://arxiv.org/abs/2610.10536)
- **EngramEdit: Decoupled Knowledge Updates in LLMs through Conditional Memory** — knowledge updates for conditional-memory architectures like DeepSeek Engram (n-gram lookup embeddings). [abs/2610.10533](https://arxiv.org/abs/2610.10533)
- **Long-WAM: Scaling the Context of World-Action Models** — model-system framework scaling causal world-model context for real-time robot control. [abs/2610.10528](https://arxiv.org/abs/2610.10528)
- **Rephrase Before You Act: Characterizing and Mitigating Language Sensitivity in Vision-Language-Action Models** — VLAs don't inherit VLM language robustness; one-word edits move success by tens of points. [abs/2610.10526](https://arxiv.org/abs/2610.10526)
- **RoboJEPA: Scaling Robotic Latent World Models** — principled scaling estimates for latent world-model capability vs size/data. [abs/2610.10515](https://arxiv.org/abs/2610.10515)
- **RECAST: Learning to Compute the Right Context through Adaptive Evidence Routing** — adaptive evidence routing as an alternative to fixed similarity-based RAG. [abs/2610.10507](https://arxiv.org/abs/2610.10507)
- **QuadTok: Quadtree Visual Tokenizer for Autoregressive Image Generation** — hierarchical quadtree visual tokens instead of 2D grids/1D sequences. [abs/2610.10497](https://arxiv.org/abs/2610.10497)
- **Before They Can Solve: Predicting Post-Training Coding-Agent Performance from Base Models** — pass@K is a poor fit for picking which base checkpoint deserves expensive agentic post-training. [abs/2610.10478](https://arxiv.org/abs/2610.10478)
- **Tetris3D: 3D Scene Generation With Objects That Fit Together** — single-image 3D reconstruction with physically/geometrically coherent multi-object scenes. [abs/2610.10539](https://arxiv.org/abs/2610.10539)
- **GRACE: Generation-aware latent compression for efficient video generation** — training highly-compressed video autoencoders to accelerate video DiTs. [abs/2610.10524](https://arxiv.org/abs/2610.10524)
