## 🔥 Top Stories

**Ox Alpha burned through 26T tokens in four days — and the "is it GLM?" case keeps building.** OpenCode reports the stealth model consumed 26T tokens since its free week opened Aug 21 ([x.com/opencode](https://x.com/opencode/status/2091946582790766899)). dejan.ai's "Ox Alpha Is GLM?" post (78 pts HN) argues prompt-injection probes + gzip-based NCD analysis both point to Z.ai's GLM ([dejan.ai/blog/ox-alpha](https://dejan.ai/blog/ox-alpha/)) — echoing Elder Plinius's unverified Aug-24 claim ([x.com/elder_plinius](https://x.com/elder_plinius/status/2090910167345049661)). Still unconfirmed; the model's own system prompt still says only "undisclosed organization." 1littlecoder notes users claim it shows continual learning and want benchmarks ([x.com/1littlecoder](https://x.com/1littlecoder/status/2091932317183058181)). The free week continues on [Nous Portal](https://portal.nousresearch.com) ([announcement](https://x.com/NousResearch/status/2090899914700054780)).

**Liquid AI ships Pipette — an on-device evaluation suite built with Artificial Analysis.** It measures how capable small models are at typical on-device tasks and how fast they run on popular phones, starting with iPhone testing ([x.com/liquidai](https://x.com/liquidai/status/2091906366428598284)). AA is launching mobile intelligence/speed benchmarks as a new vertical ([x.com/ArtificialAnlys](https://x.com/ArtificialAnlys) via [x.com/liquidai](https://x.com/liquidai/status/2091923390945005965)), following Liquid's on-device LFM2.5 line.

**Thomson Reuters launches "Thomson" — a frontier-grade LLM built on open-source for ~$40M.** Announced Aug 24, it starts from a strong OSS base and is mid/post-trained on Westlaw, Practical Law, Checkpoint, and Reuters content with hundreds of SMEs. Early evals claim parity with frontier models; it already powers CoCounsel Legal ([thomsonreuters.com](https://www.thomsonreuters.com/en/press-releases/2026/august/thomson-reuters-leverages-its-world-class-data-assets-to-launch-its-own-frontier-model)). 107 pts on HN.

**OpenAI brings back the 5-hour usage cap for ChatGPT Plus (Work + Codex).** Per TestingCatalog, the limit returns tomorrow and stays off the Pro $100/$200 tiers "for the upcoming months," framed as compute load-smoothing ([x.com/testingcatalog](https://x.com/testingcatalog/status/2092158011879940249), [x.com/testingcatalog](https://x.com/testingcatalog/status/2092058556707344708)).

**Meituan's LongCat-2.0 goes fully open source — 1.6T total / 48B-active MoE, 1M context.** Availability landed via OpenCode Go ([x.com/opencode](https://x.com/opencode/status/2091886759298654383)). It's been on OpenRouter as `meituan/longcat-2.0` since July 20 ([openrouter.ai](https://openrouter.ai/meituan/longcat-2.0)); the genuinely new part is the open-weights release.
