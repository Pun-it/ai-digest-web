# AI Daily Digest — 2026-08-26

## 🔥 Top Stories

**NVIDIA Dynamo shadow engine recovery cuts cold restart from minutes to 7.3 seconds.** NVIDIA AI posted about a new preview feature in NVIDIA Dynamo: a standby engine stays warmed up and ready to take over when an LLM engine crashes. In a GLM-5.2 test, it restored capacity in 7.3 seconds — nearly 39x faster than a cold restart. The feature targets production inference uptime. ([x.com/NVIDIAAI](https://x.com/NVIDIAAI/status/2092371238635307116))

**Anthropic pitches more than $30 trillion in potential revenue to investors.** The Wall Street Journal reports Anthropic is likely to tell investors its potential revenue opportunities exceed $30T, topping SpaceXAI's $28.5T estimate. The figure landed the same week Anthropic shipped a major Claude memory update (see below). ([x.com/WSJ](https://x.com/WSJ/status/2092286402423660714)) · ([x.com/testingcatalog](https://x.com/testingcatalog/status/2092301068596027428))

**Claude gets unified memory across Chat and Cowork, plus a Morning Brief feature.** Anthropic rolled out a unified memory system that spans Claude Chat and Claude Cowork, letting Cowork start tasks from what Claude already knows from prior chats. A new toggle lets users keep sensitive topics out of memory, and memories are now split into categories with a dedicated tab. Separately, a Morning Brief feature is rolling out to some users, running on scheduled tasks to guide preferences and Connectors setup. ([x.com/testingcatalog](https://x.com/testingcatalog/status/2092382971944702272)) · ([x.com/claudeai](https://x.com/claudeai/status/2092299704864284888))

**Keenable launches independent web search API for AI labs and agents.** Keenable announced an AI-native search API running on its own crawler, index, and ranking stack across more than 100 billion documents, with p95 latency under 250ms from US East. The company raised a $26M seed round led by Accel. ([x.com/testingcatalog](https://x.com/testingcatalog/status/2092325555656098276)) · ([x.com/styskin](https://x.com/styskin/status/2092265673041084505))

**Nous Research: Solar Pro 4 free via Nous Portal + Hermes MCP Connectors Catalog expands to 44 new connections.** Nous Research announced Solar Pro 4 is free exclusively through Nous Portal for another week, in partnership with Upstage. Separately, the Hermes Agent built-in MCP Connectors Catalog expanded to offer 44 new connections for apps like Cloudflare, Datadog, Metabase, GitLab, Railway, and DeepWiki, with one-click setup in Hermes Desktop. ([x.com/NousResearch](https://x.com/NousResearch/status/2092351725571088884)) · ([x.com/Teknium](https://x.com/Teknium/status/2092321384085299665))

## 📄 New Research Papers

From arXiv cs.AI | cs.LG | cs.CL | cs.CV, August 25 submissions:

1. **Do Robotic World Models Really Follow Actions?** — Diagnoses and aligns action-conditioned generation for policy learning; shows generated futures often deviate from intended actions. ([arxiv.org/abs/2608.24885](https://arxiv.org/abs/2608.24885))

2. **Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses** — Introduces Recuris, a recursive self-improvement framework that uses experiential-working memory to prevent skill invocation misalignment in long-horizon tasks. ([arxiv.org/abs/2608.24876](https://arxiv.org/abs/2608.24876))

3. **SPO++: Stream-Aligned Policy Optimization for Asynchronous Agentic RL** — Removes the need to wait for sibling rollouts in group-relative RL, critical for long and variable tool-use trajectories. ([arxiv.org/abs/2608.24870](https://arxiv.org/abs/2608.24870))

4. **BrowserForge: Scaling Web Episode via Parallel Browser Sandboxes** — Trains web agents from rendered pixels using parallel browser sandboxes to generate high-quality interaction data at scale. ([arxiv.org/abs/2608.24848](https://arxiv.org/abs/2608.24848))

5. **LAION-BVD: A 10-Million-Hour Open Video Dataset for Multimodal Pre-training** — 1.3B platform-specific video URLs from CommonCrawl, 80M videos downloaded, for large-scale multimodal learning. ([arxiv.org/abs/2608.24845](https://arxiv.org/abs/2608.24845))

6. **LeFlow: Generative Latent Flow Planning for World Models** — Uses latent world models for action planning without online trajectory optimization, enabling efficient planning in latent space. ([arxiv.org/abs/2608.24855](https://arxiv.org/abs/2608.24855))

7. **CAFE: Self-Improving Search Agents Need Co-Evolving Feedback** — Outcome-supervised search agents need intermediate feedback that co-evolves with the agent to localize errors before they compound. ([arxiv.org/abs/2608.24794](https://arxiv.org/abs/2608.24794))

8. **StarHarness: Evolving Harnesses with Stratified Search for Enterprise Environments** — Framework for evolving environment-specific agent harnesses while keeping model weights fixed; includes prompt/task framing, tool interfaces, and skill libraries. ([arxiv.org/abs/2608.24804](https://arxiv.org/abs/2608.24804))

9. **Effective Learning Rate Governs Loss Dynamics in Language Model Pretraining** — Uncovers ELR collapse: learning rate and parameter norm govern loss dynamics primarily through their ratio (effective learning rate). ([arxiv.org/abs/2608.24814](https://arxiv.org/abs/2608.24814))

10. **Linear Probing Provides Robust and Efficient Detection of Machine-Generated Text** — Shows linear probing on hidden states outperforms supervised detectors for out-of-domain machine-generated text detection. ([arxiv.org/abs/2608.24780](https://arxiv.org/abs/2608.24780))
